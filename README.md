# Cron

A Small, Simple and Lightweight shell written in C.

## BUILD

```
make
```

Uses `GCC` and build `Object files`

## USAGE

```
./build/cron
```

## WHAT WORKS CURRENTLY??

### Basic commands

- ls
- cmatrix
- pipes.sh

### 2 word commands

- ls | grep .c
